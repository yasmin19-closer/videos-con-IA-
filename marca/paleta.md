# Paleta de marca · Yasmin Álvarez | High Ticket Closer

| Color | Código | Uso |
|---|---|---|
| Negro cálido | `#1C1B19` | Fondos principales |
| Naranja | `#F08A3C` | Palabras clave, botones y detalles (solo lo importante) |
| Crema | `#F3EEE4` | Fondos claros y tarjetas |
| Blanco suave | `#FFFDF8` | Textos sobre fondo oscuro |

Tipografía: Inter Display (Black para titulares, Bold para textos).
